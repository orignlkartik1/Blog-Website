# Blog Website

A modern, responsive blog website built with Python, HTML, and CSS.

## 📋 Overview

This is a feature-rich blog platform that allows users to create, read, and manage blog posts. The application combines Python backend logic with a clean and responsive HTML/CSS frontend.

## 🛠️ Technology Stack

- **Backend**: Python (45.9%)
- **Frontend**: HTML (40.5%)
- **Styling**: CSS (13.6%)

## ✨ Features

- Clean and responsive design
- Easy-to-navigate blog interface
- Support for creating and managing blog posts
- Optimized for all devices (mobile, tablet, desktop)

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- A modern web browser

### Installation

1. Clone the repository:
```bash
git clone https://github.com/orignlkartik1/Blog-Website.git
cd Blog-Website
```

2. Install required dependencies (if applicable):
```bash
pip install -r requirements.txt
```

3. Run the application:
```bash
python app.py
```

4. Open your browser and navigate to `http://localhost:5000` (or the configured port)

## 📝 Usage

- **Create a Post**: Navigate to the create post section and fill in the blog details
- **View Posts**: Browse all available blog posts on the homepage
- **Edit Posts**: Modify existing blog posts
- **Delete Posts**: Remove posts you no longer need

## 🎨 Customization

The website uses standard CSS for styling. You can customize the appearance by modifying the CSS files in the project.
